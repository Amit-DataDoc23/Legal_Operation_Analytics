## Features & Implementation
- **Slicers**: Added for filtering by Year & Clear Slicers/Interaction.
- **DAX Measures**:  
  - `CALCULATE()` for conditional aggregations  
  - `SUM()for revenue/profit totals  
  - `AVERAGE()for satisfaction scores  
  - `DIVIDE() for ratios (profit margin, utilization) and so on.  
- **Bookmarks**: Used for navigation between pages and slicers interactivity.
